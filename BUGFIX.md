## 1. Состояние не в useState

В исходнике всё через обычные `let` внутри компонента.
При клике на «Добавить» данные в массиве менялись, но React об этом не знал и не делал ререндере поэтому на экране ничего не менялось.
То же самое с селектом и инпутом количества. Значение присваивалось в переменную, а UI оставался прежним.
Починил через `useState` для списка услуг, выбранного id и quantity.

## 2. Мутации массива

`push` и `splice` и прямое изменение `existing.quantity` плохая идея даже со стейтом.
Нужно возвращать новый массив, иначе можно словить кейсы, когда обновление не подхватится.

## 3. Сравнение услуг по ссылке

Было `item.service === service`.
Надёжнее сравнивать по `id`

## 4. removeService

Удаление тоже перевёл на filter по id, без splice по ссылке на объект
